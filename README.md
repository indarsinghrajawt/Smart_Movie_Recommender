Project Overview

Smart Movie Recommendation System is a Streamlit-based web application that recommends movies using the TMDB (The Movie Database) API.

Users can:
- Browse Bollywood and Hollywood movies
- Explore mood-based categories
- Search for any movie
- Add movies to favorites
- Watch trailers directly from YouTube

This project demonstrates API integration, dynamic UI rendering, session state handling, and cloud deployment using Python and Streamlit.

------------------------------------------------------------

Features

- Bollywood and Hollywood category filters
- Mood-based recommendations (Feel Good, Emotional, Thriller, Sci-Fi, etc.)
- Movie search functionality
- Randomized movie suggestions
- Add to Favorites section
- Trailer link integration
- Responsive grid layout
- Secure API key management

How To Run Locally

1. Clone the repository
2. Install dependencies:
   pip install -r requirements.txt
3. Run the app:
   streamlit run app.py
