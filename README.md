# 🎬 Smart Movie Recommendation System

A Streamlit based movie recommendation web app using TMDB API.

## 🚀 Features
- Bollywood & Hollywood categories
- Mood based filters
- Movie search
- Add to favorites
- Trailer links

## 🛠 Tech Stack
- Python
- Streamlit
- TMDB API

## ▶ Run Locally

pip install -r requirements.txt  
streamlit run app.py
